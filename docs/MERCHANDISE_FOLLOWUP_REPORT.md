## 16. Реальные ограничения

На срезе лишь шесть дней сезона; 125 дат коммерческого входа неизвестны, часть базы/факта/сроков отсутствует. Для размера и распределения нет утверждённых порогов. Нельзя подтвердить распределение продаж по партиям. История остаётся контекстом, не заменяет актуальные данные. NOS и неоднозначные узкосезонные нормы требуют явных бизнес-правил.

Прогноз отличается от Skill намеренно: у приложения строгий консервативный темп и неполное покрытие. План отличается из-за разрешённой точной категорийной замены. Неизвестные недельные значения не превращены в нулевые продажи. Старые запуски автоматически не пересчитываются; нужен новый запуск с тремя файлами.
