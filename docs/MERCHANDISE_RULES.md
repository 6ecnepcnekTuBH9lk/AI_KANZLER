## Принятые интерпретации

База, факты и недостающие планы не восстанавливаются предположениями. При отсутствии хотя бы одного значения общий итог соответствующего показателя — `null`; отдельно доступны сумма известных значений и число покрытых артикулов. Выполнение сопоставимого набора рассчитывается только по строкам, где одновременно есть база, план и факт. Эти показатели записаны и в UI, и в сводку Excel.

Месячные единицы нормируются на утверждённый целевой процент; месячные проценты должны согласовываться с ним. Неполная официальная недельная кривая не заменяется молча. План не сдвигается при позднем входе. Если кривая содержит продажи после явного нормативного срока, она сохраняется и выдаётся QA-конфликт, срок прогноза не продлевается.

Без специального срока применяется верхняя корпоративная граница: шесть месяцев, для костюмной группы 180 дней, с ограничением концом сезона и сообщением QA. Индивидуальный выбор внутри диапазона 3–6 или 4–6 месяцев требует утверждённого срока в плане.

Ранний темп может содержать предсезонные недели: прогноз помечается условным. Сам по себе он не подтверждает ХИТ или ценовую силу; для ХИТа нужны минимум две завершённые недели внутри сезона. Официальное выполнение всегда рассчитано только по сезонному факту.

## Операционные подтверждения во входе

Поддерживаются дополнительные колонки FACT со значениями «Да»/«Нет»; пусто означает «не проверено». Точные имена собраны в `importers.BOOLEAN_FIELDS`: представленность, ходовые размеры, распределение, подсортировка, остановка подсортировки, сокращение магазинов, перераспределение через склад, смена канала, экономика/запас/канал второй поставки, ценовой потенциал и эффект переоценки. Значения должны отражать фактическую проверку ответственным, а не заполняться ради получения скидки.

Без подтверждений приложение предлагает следующую операционную проверку. При доказанном выполнении условий — ценовой тест/переоценку в рамках 3–5%, 5–10/10–15/15–20 п.п. и предельных скидок 40/50/60%. Не назначает магазин → магазин как штатное действие.

По этим пунктам полная готовность согласно исходному Definition of Done не заявляется. Приложение пригодно для проверяемого расчётного пилота; утверждение самостоятельных коммерческих решений требует завершения перечисленных правил.
