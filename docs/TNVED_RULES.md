## Проверка доказательств

Дерево Alta используется для поиска кандидатов. Каждая конечная позиция повторно открывается по `/tnved/code/<10 цифр>/`; проверяются маркер кода, полный путь и описание. В результат сохраняются URL, время проверки, SHA256 страницы и описания уровней. Три состояния проверки — соответствует, исключён, не разрешён. Код записывается только при одном соответствии и отсутствии неразрешённых альтернатив.

Процентный состав анализируется по основному материалу до подкладки/наполнителя. Цвет и артикул не образуют отдельный запрос. Неизвестные составляющие, ничья материалов и противоречивый трикотаж требуют уточнения. Признаки конструкции входят в сигнатуру и препятствуют объединению разных товаров.

Коды — текст из десяти цифр. Существующие значения, даже короткие или формулы, сохраняются без проверки по умолчанию и имеют отдельный статус. Они не выдаются за вновь подтверждённые коды. При явно включённой проверке существующего кода неопределённость приводит к пустому новому коду и причине.

## Сохранение Excel

openpyxl используется для чтения. Сохранение выполняется точечной правкой OOXML через lxml, чтобы не потерять неподдерживаемые расширения, изображения и прочие части книги. Оригинал не перезаписывается. Изменённые ячейки проверяются, остальные части ZIP сравниваются. Если комментарий содержит формулы, они сохраняются, а объяснение пишется справа в «Комментарий ТН ВЭД»; это явное исключение из использования существующей колонки ради сохранности формул.

## Ограничения по разделам Skill

- **3–4:** реализовано публичное дерево и проверка конечной позиции. Нет полноценного итеративного поиска по всем примерам `/tik/` и автоматического чтения пояснений для каждой спорной ветви. Для расширения нужен адаптер этих источников с проверяемыми правилами перехода к кандидатам.
- **5, 7–8:** поддерживается ограниченный набор изделий и условий. Технические подсубпозиции (плотность, масса, способ вязки, специальные назначения и остаточные «прочие») направляются на уточнение. Это ограничение классификатора, даже когда человек способен определить код по полному описанию. Требуются правила конкретных ветвей и тестовые примеры, подтверждённые специалистом.
- **6:** недостающие признаки обуви перечисляются, но финальная автоматическая классификация обуви сейчас не выполняется даже при полном наборе признаков. Нужна отдельная реализация условий групп 6401–6405 и проверенные примеры.
- **13–14:** программно проверяется структура и сохранность OOXML; визуальный просмотр в Microsoft Excel и печать на всех корпоративных шаблонах не выполнялись.

Эти ограничения не скрываются под технической ошибкой Alta. В реальном прогоне 57 строк: 13 кодов подтверждены, 44 требуют уточнения, технических ошибок 0. Результат не является доказательством полного покрытия всего классификатора ТН ВЭД.
