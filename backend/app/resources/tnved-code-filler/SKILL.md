Заполнение кодов ТН ВЭД по данным Alta.ru

Назначение

Ты обрабатываешь Excel-файл со списком номенклатуры и должен определить для каждой товарной позиции соответствующий 10-значный код ТН ВЭД ЕАЭС, используя информацию с сайта https://www.alta.ru/.

Результатом должен быть Excel-файл той же структуры и оформления, что и исходный, но с заполненной колонкой «Код ТНВЭД».

Если определить код достоверно невозможно, не угадывай его. В таком случае укажи причину в колонке «Комментарий».

1. Входные данные

На вход пользователь передает Excel-файл .xlsx.

Типовая структура файла содержит колонки:

Код

Артикул

Номенклатура

Наименование

Марка (бренд)

Код ТНВЭД

Пол

Дата изготовления

Цвет

Трикотаж

Состав

Расположение колонок может изменяться, поэтому определяй их по заголовкам, а не по фиксированным номерам столбцов.

При поиске заголовков допускай незначительные различия в пробелах, например:

Код ТНВЭД

Код ТН ВЭД

Считай их одной и той же колонкой.

Если колонки Код ТНВЭД нет, создай ее.

2. Основная задача

Для каждой строки с товаром:

Прочитай все доступные характеристики товара.

Определи характеристики, влияющие на классификацию по ТН ВЭД.

Найди на сайте Alta.ru наиболее подходящую товарную позицию.

Проверь найденный вариант по действующей структуре ТН ВЭД.

Определи полный 10-значный код ТН ВЭД.

Запиши его в колонку Код ТНВЭД.

Код записывай как текст без пробелов, например:

6105100000

В ячейке должно находиться ровно 10 цифр.

Не записывай только группу, товарную позицию или неполный код из 4, 6 или 8 цифр.

3. Какие источники использовать

Основным источником информации является только сайт Alta.ru.

Используй в первую очередь следующие разделы:

ТН ВЭД

https://www.alta.ru/tnved/

Используй для:

поиска по наименованию;

просмотра дерева ТН ВЭД;

проверки полного 10-значного кода;

проверки официального описания товарной позиции.

Товары и коды

https://www.alta.ru/tik/

Используй для поиска примеров того, какие коды применялись для аналогичных товаров в практике декларирования.

Не считай найденный здесь пример достаточным основанием сам по себе. После этого проверь соответствующий код в актуальной ТН ВЭД.

Пояснения к ТН ВЭД

https://www.alta.ru/poyasnenia/

Используй, если необходимо определить различия между близкими товарными позициями или понять, какие характеристики являются классифицирующими.

Подбор кода

https://www.alta.ru/codesearch/

Используй как дополнительный способ поиска, если сервис доступен.

Если сервис требует авторизацию или недоступен, продолжай поиск через остальные открытые разделы Alta.ru.

Допускается использовать обычный веб-поиск с ограничением результатов доменом alta.ru, если внутренний поиск сайта не дает удобного результата.

Не используй код с другого сайта как окончательный источник классификации.

4. Формирование поискового запроса

Не выполняй поиск только по значению Номенклатура.

Используй максимально полный набор значимых характеристик товара.

В первую очередь учитывай:

Номенклатура;

Наименование;

Пол;

Трикотаж;

Состав.

При необходимости учитывай другие характеристики из строки.

Артикул, Код, Марка (бренд), Дата изготовления и Цвет обычно не являются основными классифицирующими признаками и не должны влиять на выбор кода, если из ТН ВЭД не следует обратное.

Например, вместо поиска:

футболка

формируй смысловой запрос примерно такого вида:

футболка мужская трикотажная 77% лиоцелл 20% шерсть

Поиск выполняй итеративно.

Сначала найди подходящую группу или товарную позицию, затем уточняй код с помощью характеристик товара.

5. Правила классификации одежды

Для одежды обязательно учитывай как минимум:

Вид изделия

Например:

футболка;

джемпер;

брюки;

джинсы;

пиджак;

куртка;

плащ;

пальто;

полупальто;

галстук;

другое изделие.

Способ изготовления

Используй значение колонки Трикотаж.

Если:

Трикотаж = Да

рассматривай товар как трикотажное/вязаное изделие, если остальные сведения не противоречат этому.

Если:

Трикотаж = Нет

не относись к товару как к трикотажному без дополнительных оснований.

Этот признак критически важен, поскольку трикотажные и нетрикотажные изделия могут относиться к разным группам ТН ВЭД.

Пол

Учитывай:

мужской;

женский;

детский,

если соответствующая позиция ТН ВЭД разделяется по этому признаку.

Состав

Проанализируй процентное содержание материалов.

Например:

20% шерсть, 77% лиоцелл, 3% эластан

Не выполняй поиск просто по первому указанному материалу.

Определи, какой материал или группа материалов являются классифицирующими для соответствующей товарной позиции.

Не путай основной материал изделия с:

подкладкой;

наполнителем;

отделкой;

стелькой;

другими вспомогательными элементами.

Если состав содержит основной материал и отдельно подкладку, для классификации основного изделия используй именно основной материал, если ТН ВЭД не предусматривает иное.

6. Правила классификации обуви

Для обуви используй особенно строгий режим проверки.

Для выбора полного кода могут иметь значение:

тип обуви;

материал верха;

материал подошвы;

закрывает ли обувь лодыжку;

длина стельки;

пол;

специальное назначение;

дополнительные конструктивные характеристики.

Например, строка:

Обувь (Лоферы)

с составом:

натуральная замша; подкладка: натуральная кожа; стелька: натуральная кожа; подошва: резина

содержит значительно больше классифицирующей информации, чем строка:

Обувь

с составом:

натуральная кожа.

Не делай вывод, что натуральная кожа автоматически означает конкретный 10-значный код обуви.

Если для выбора между несколькими кодами необходима информация о подошве, длине стельки, закрытии лодыжки или другой характеристике, которой нет в файле, код не подставляй.

В Комментарий укажи, какие именно данные отсутствуют.

Например:

Недостаточно данных для однозначного определения кода: не указан материал подошвы и конструкция обуви.

Или:

Найдено несколько возможных кодов. Для выбора требуется информация о том, закрывает ли обувь лодыжку и о длине стельки.

7. Проверка найденного кода

Перед записью каждого кода обязательно проверь:

Код существует в актуальной ТН ВЭД на Alta.ru.

Код содержит ровно 10 цифр.

Описание кода соответствует виду товара.

Материал соответствует характеристикам товара.

Способ изготовления соответствует товару.

Пол соответствует товару, если он влияет на классификацию.

Отсутствуют дополнительные условия позиции, которым товар явно не соответствует.

Не выбирай код только потому, что Alta.ru показала его первым в результатах поиска.

8. Работа с неоднозначными результатами

Если найдено несколько возможных 10-значных кодов, сравни условия каждой позиции с характеристиками товара.

Выбирай код только тогда, когда имеющихся данных достаточно для исключения остальных вариантов.

Если однозначно выбрать код нельзя, не угадывай.

Оставь Код ТНВЭД пустым и запиши причину в Комментарий.

Примеры комментариев:

Недостаточно характеристик товара для определения полного 10-значного кода.

Найдено несколько подходящих кодов; в исходном файле отсутствуют данные, позволяющие выбрать один из них.

Не указан материал подошвы обуви.

Не указан тип конструкции обуви.

Не удалось определить, является ли изделие трикотажным.

Состав товара указан недостаточно подробно.

По указанным характеристикам соответствующий товар на Alta.ru не найден.

9. Недоступность Alta.ru

Если Alta.ru временно недоступна, возникает техническая ошибка, блокировка или невозможно открыть необходимые страницы:

не пытайся определить код исключительно по собственным знаниям.

Оставь Код ТНВЭД пустым.

В колонке Комментарий укажи, например:

Не удалось проверить код на Alta.ru: сайт или необходимый раздел недоступен.

Если отдельный сервис Alta.ru требует авторизацию, но информация доступна через другой открытый раздел Alta.ru, используй открытый раздел и продолжай работу.

10. Колонка «Комментарий»

Не добавляй колонку Комментарий, если все товары успешно классифицированы.

Если хотя бы для одной строки определить код не удалось:

найди существующую колонку Комментарий;

если ее нет — добавь новую колонку Комментарий.

Добавляй ее справа от существующей таблицы, не меняя порядок остальных колонок.

В комментарии указывай конкретную причину, а не общие формулировки вроде:

Не найдено

или:

Ошибка.

Комментарий должен позволять пользователю понять, какие сведения необходимо получить для классификации товара.

Если колонка Комментарий уже существовала и содержала пользовательский текст, не удаляй его. При необходимости добавь новый комментарий аккуратно, не создавая дубликатов.

11. Повторяющиеся товары

Перед поиском анализируй товары на наличие одинаковых классифицирующих характеристик.

Если несколько строк имеют одинаковые:

вид товара;

пол;

признак трикотажа;

основной состав;

другие значимые классифицирующие характеристики,

можно классифицировать их как одну группу и использовать один подтвержденный код для всех соответствующих строк.

Например, разные цвета одного и того же мужского галстука одинакового материала обычно не требуют повторного полного поиска, если цвет не влияет на классификацию.

При этом нельзя объединять товары только по похожему названию.

Например, обувь с разными материалами верха или подошвы должна анализироваться отдельно.

Группировка используется только для ускорения обработки и обеспечения единообразия результата.

12. Уже заполненные коды

Если в колонке Код ТНВЭД уже есть значение, по умолчанию не изменяй его.

Обрабатывай строки, в которых код отсутствует.

Проверяй и исправляй ранее заполненные коды только в том случае, если пользователь отдельно попросил выполнить проверку существующих кодов.

13. Работа с Excel

Исходный файл является шаблоном результата.

Не перестраивай таблицу заново.

Сохрани:

все листы;

названия листов;

порядок строк;

порядок существующих колонок;

формулы;

объединенные ячейки;

фильтры;

ширину колонок;

высоту строк;

шрифты;

размеры шрифтов;

цвет текста;

заливку;

границы;

выравнивание;

числовые форматы;

закрепленные области;

другие элементы оформления исходного файла.

Изменяй только необходимые ячейки.

Оформление заполненных ячеек Код ТНВЭД должно соответствовать остальным ячейкам этой колонки.

Коды ТН ВЭД обязательно сохраняй как текст, чтобы Excel не изменял значение.

Если создается новая колонка Комментарий:

оформление заголовка должно соответствовать другим заголовкам таблицы;

оформление строк должно соответствовать соседним ячейкам;

включи перенос текста;

установи разумную ширину колонки, достаточную для чтения комментариев.

Не изменяй исходный файл пользователя непосредственно. Создай новый результирующий файл.

14. Контроль качества перед сохранением

Перед формированием результата обязательно выполни итоговую проверку.

Убедись, что:

количество товарных строк не изменилось;

ни одна исходная строка не удалена;

порядок строк не изменился;

исходные значения не изменены;

существующие колонки не удалены;

для каждой строки без исходного кода выполнена попытка классификации;

каждый успешно найденный код содержит ровно 10 цифр;

код подтвержден информацией Alta.ru;

одинаковые товары классифицированы последовательно;

отсутствуют придуманные или непроверенные коды;

каждая строка без определенного кода имеет понятный комментарий с причиной;

оформление исходного Excel сохранено.

Дополнительно проверь, что в колонке Код ТНВЭД отсутствуют значения вида:

2 цифры;

4 цифры;

6 цифр;

8 цифр;

текстовое название позиции;

код с пробелами;

несколько альтернативных кодов в одной ячейке.

Если есть несколько возможных вариантов, они должны быть описаны в Комментарий, а ячейка Код ТНВЭД должна оставаться пустой.

15. Формирование выходного файла

Результат сохрани в формате .xlsx.

Название сформируй из имени исходного файла, добавив:

_с_кодами_ТНВЭД

Например:

Исходный файл:

Артикулы_коллекции_ВЛ_27_Нет_кодов_ТНВЭД.xlsx

Результат:

Артикулы_коллекции_ВЛ_27_Нет_кодов_ТНВЭД_с_кодами_ТНВЭД.xlsx

После завершения предоставь пользователю готовый Excel-файл.

Также кратко сообщи:

сколько товарных строк обработано;

для скольких найден код;

для скольких код определить не удалось.

Не выводи пользователю длинный промежуточный отчет, если он его не запрашивал.

Главный результат работы — готовый Excel-файл.
